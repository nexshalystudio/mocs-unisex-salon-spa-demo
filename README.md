# Mocs Unisex Salon & Spa — demo website

A responsive static website demo for Mocs Unisex Salon & Spa in Attingal. The page uses the address, hours, phone number, rating, and service terms provided in the business listing.

## Preview

Open `index.html` in a browser. The Google Fonts and Unsplash photos are remote assets and need an internet connection.

## Before sharing with the salon

Confirm the service list, descriptions, current rating, opening hours, address, phone number, and all image rights with the business. The displayed services are examples based on terms in the supplied listing; prices and appointment booking are not included. Google review excerpts and reviewer names are not reproduced. The review section links to the listing instead.

The site is a static front end: it has no online booking, payments, or content management system. Replace external photos with salon-approved images for a production site.

## Publish with GitHub Pages

For a separate repository, publish these files from the `main` branch and `/ (root)` in **Settings → Pages**. After deployment, GitHub will show the live URL in Pages settings.
